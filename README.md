### 📌 Featured Projects

#### 1. Health Application Review Sentiment Analysis

Analyzed user reviews from health applications to understand customer sentiment and identify opportunities for service improvement.

- Cleaned and processed user reviews using Python and Pandas.
- Analyzed positive, negative, and neutral sentiment distributions across different health applications.
- Applied the Chi-square statistical test to examine associations between applications and sentiment.
- Identified recurring feedback themes, including consultation experiences, payment issues, response times, and medicine delivery.
- Created visualizations to communicate findings and support data-driven recommendations.

**Tech Stack:** Python, Pandas, Statistical Analysis, Tableau

#### 2. Tokopedia Web Scraping & Sales Analysis — August 2026

Analyzed Tokopedia clothing products (*baju*) to explore potential opportunities for a dropshipping business and developed an interactive Tableau dashboard to monitor key business metrics.

- Collected product data through web scraping.
- Cleaned, transformed, and analyzed data using Python, Pandas, and NumPy.
- Explored product prices, sales quantities, ratings, seller locations, and discounts to identify market patterns.
- Conducted exploratory data analysis using Matplotlib and Seaborn.
- Developed an interactive Tableau dashboard featuring KPIs, top 10 products, and the relationship between revenue and seller location.
- Generated insights to support product evaluation and data-driven dropshipping decisions.

**Tech Stack:** Python, Pandas, NumPy, SciPy, Matplotlib, Seaborn, Tableau, Web Scraping

#### 3. Sephora Lipstick Product ETL Pipeline

Developed an ETL pipeline to collect, process, and store lipstick product data from the Sephora website in PostgreSQL.

- Scraped lipstick product data from Sephora using Python and Beautiful Soup.
- Performed exploratory data analysis and cleaned raw product data using Pandas.
- Transformed raw data into a structured format for database storage.
- Created and populated a PostgreSQL database with the cleaned product dataset.

**Tech Stack:** Python, Pandas, Beautiful Soup, Web Scraping, PostgreSQL

#### 4. Indonesia Job Salary Analysis — Team Project

Collaborated with a team to analyze average job salaries across job categories, companies, and locations in Indonesia.

- Performed exploratory data analysis and statistical testing.
- Examined salary distributions and differences across job categories and companies.
- Explored the relationship between job openings and average salaries.
- Helped communicate findings through a Tableau dashboard.

**Tech Stack:** Python, SQL, PostgreSQL, Apache Airflow, Great Expectations, Tableau

#### 5. IBM HR Employee Attrition — ETL Project

Worked with an employee attrition dataset as part of a data engineering and analytics project.
